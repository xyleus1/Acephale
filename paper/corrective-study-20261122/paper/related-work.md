# Related work

PASTE combines historical tool-pattern and argument-map prediction with isolated speculative tool execution. Its scheduler prioritizes authoritative work and selects speculative work using confidence, expected latency benefit and resource use. A separate LLM-tool co-scheduler regulates the interaction with model execution. Results are matched to the eventual tool name and arguments; safe execution policies remain necessary for side effects. Acephale adopts an application-level prefetching design inspired by these ideas, but does not reproduce PASTE's complete implementation, engine-level pacing or reported performance. The preserved protocol appendix uses the broad term "cost-aware"; the scheduling comparison here refers to confidence-, latency-benefit- and resource-aware utility, not to an equivalent dollar-denominated accounting ledger. [Sui et al., version 3, Sections 4.1-4.3](https://arxiv.org/html/2603.18897v3#S4).

Speculate with Memory supplies a model speculator with online transition statistics, context-retrieved trajectory segments and recurring-confusion constraints. It studies action, observation and chained prediction under validation and safe speculative-execution restrictions. Its main prediction comparisons replay fixed actor trajectories, while a separate experiment examines live latency. Acephale instead binds versioned memory publications, constructs a common candidate panel from public argument evidence, and optionally conditions the ranking on source-grounded goals. It does not claim to reproduce all three online memories, the observation/chained modes, or that paper's reported gains. Verified speculative output does not imply zero physical work or zero API expense. [Li et al., version 1, Sections 2.1-2.2](https://arxiv.org/html/2607.12236v1#S2), [evaluation scope](https://arxiv.org/html/2607.12236v1#S3.SS1), and [live latency validation](https://arxiv.org/html/2607.12236v1#S4.SS3).

The tau2-bench environment paper [3] and pinned upstream source [4] provide the native provenance. The native environment is pinned to tau2-bench commit 2174a603f6d014ef94473ffa95957f6ce27100db. Custom task composition and restricted coverage must be disclosed. This provenance alone does not establish official benchmark comparability. [Pinned upstream source](https://github.com/sierra-research/tau2-bench/tree/2174a603f6d014ef94473ffa95957f6ce27100db).
