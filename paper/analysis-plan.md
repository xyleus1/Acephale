This maps the frozen protocol to presentation artifacts. It adds no estimator, selection rule, calibration fit or numerical threshold.

Use the unchanged report scripts under the frozen, source-bound report package. Read already computed estimates and intervals from accepted reports. Do not implement a new bootstrap, alter confidence levels or change censoring treatment in plotting code.

Keep seed and deployment identities explicit. Fixed panels require common IDs and labels; selected-panel diagnostics are separate. Private labels join only after replay closure. Calibration uses the original training partition.

Native rows preserve paired block, arm order, task/family, predictor seed and trial seed. Every complete-case view must disclose all planned/dispatched/completed/failed/censored counts. Heldout eligibility follows the original selection receipt; zero eligibility yields a stated limitation, not an invented comparison.

Prefix timing is separate from episode latency. Cost views separate AWS infrastructure, hosted API cash, unresolved reservations, and billed/estimated values. Qualification startup does not predict scientific throughput.

CSV files are empty schemas. Blank numeric cells must never become zero. Each populated row requires an accepted source path/hash and denominator. Figure layouts contain no synthetic outcomes.
