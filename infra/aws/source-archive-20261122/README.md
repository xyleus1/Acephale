# Controller and operational callback source archive

This is a sanitized archive of the controller and operational helpers actually used during the AWS study continuation on 2026-11-22. It contains source code only: no live configuration, credentials, budget journal, datasets, model weights, or runnable deployment packet.

The controller uses one existing service and lock, permanent assignment ownership, versioned immutable transport evidence, finite deadlines, and explicit physical-drain evidence. CPU callbacks call the original collectors and held-out selector. Completed operations are adopted rather than repeated. The serial transport correction removes an inappropriate RPC-generation metadata check while retaining the original scientific command. The future callback correction preserves the receipt-inputs reference after iterating individual cohort receipts.

The actual original development collection retained all 36 declared rows. The original selector selected 96 declared held-out arm-runs in two whole segments. This archive does not assert held-out execution, scientific acceptance, or study completion. Direct execution remains explicitly UNVALIDATED. Measured-timing validity is retained from the original output.

Cloud account IDs, bucket names, instance IDs, immutable object version identifiers, and the local user name have been replaced with examples. These archival copies are not deployment artifacts. The manifest records both original and sanitized source SHA-256 values; original source files were not modified.

The source expects the repository's original runtime, accounting, provider transports, and immutable configuration inputs. Those dependencies and live authorization are deliberately not bundled. Existing shared-controller, provider-owner, and original-budget-owner boundaries must be preserved in any operational reuse.
