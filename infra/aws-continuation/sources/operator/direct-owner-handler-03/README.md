# Deployed direct owner handler snapshot

These are sanitized copies of the deployed controller and owner handler, plus
the deployed direct-mode guard. The source manifest records the original and
published hashes separately. Account, study-table and deployment-root literals
use explicit example values. Every other source byte is preserved.

The handler runs inside the existing controller. It consumes pinned owner
descriptors, adopts existing publication handles, uses conditional permanent
ownership for new operations, and requires physical drain evidence before
recording terminal disposition. It keeps funding classification and finite
deadlines separate from scientific acceptance. It does not allocate providers,
repeat scientific trials, or make the full scientific DAG autonomous.

This is an implementation archive, not a runnable deployment package. Do not
execute these snapshots or create another coordinator. Private configurations,
source references, owner descriptors, permissions, reservations, credentials,
worker state and financial journals are intentionally absent. The active system
continues to use its original immutable source bytes.

Publication checked source identity, reversible sanitization and Python syntax.
It did not rerun deployment tests or establish a benchmark result. The evolving
producer/emitter successor is not included.
