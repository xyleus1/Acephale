# Heldout launch repairs — source archive

This is a sanitized archive of the operational sources used to launch two whole selected heldout segments. It is not a deployment bundle. Deployment configurations, credentials, financial records, model data, worker outputs, instance identities and private storage locations are deliberately excluded. Paths under `/workspace/acephale`, `INSTANCE_*`, `RESOURCE_*` and `EXAMPLE_*` are explicit example tokens; archived scripts must not be run as a deployment recipe without the owner's actual configuration.

The original selector produced eight families and 96 arm-runs, divided into two original serving segments of 48. The original budget owner reserved all 96 parents once, at 1,250,000 microdollars per run. The same owner continues to reserve and settle provider calls. These sources do not introduce a second ledger writer.
