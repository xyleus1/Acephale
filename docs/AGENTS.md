# Documentation Guidance

- Docs are the source of truth for durable project context. Keep them concise, current, and specific.
- Update `docs/DECISIONS.md` for architecture choices future agents should follow.
- Update `docs/ENGINEERING_LOG.md` after meaningful implementation work.
- Keep `docs/AI_HANDOFF.md` useful for the next strategy or coding pass.
- Do not dump chat transcripts into docs. Convert them into decisions, tasks, caveats, or verification notes.
