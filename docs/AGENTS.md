# Documentation

Keep methods, execution instructions and observed state separate. `METHODS.md`
describes contracts and controls, `RUNBOOK.md` contains commands, and `STATE.md`
records verified results and pending gates. Keep handoff/log/decisions concise.

Use the standalone Acephale identity and current paths. Do not copy application
material, obsolete benchmark conclusions or historical verification counts into
active documentation. Never rewrite an immutable result to change its branding.
Avoid U+2014 and retain primary-source attribution for research claims.
