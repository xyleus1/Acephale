# Acephale native profiling

Use [the runbook](../RUNBOOK.md) section 7 for native/document profile configs and
commands. [Methods](../METHODS.md) describes the six timing components and v2
deployment identity. One ranking request completes before background goal refresh
overlaps the admitted read. Goal refresh is recorded separately and drained.

The profiler reconstructs private ephemeral native state and verifies public
observations. It does not execute newly proposed actor actions. At least ten
complete measurements are required, failures remain, and the result is an
admission heuristic rather than a benchmark score or demonstrated live speedup.
